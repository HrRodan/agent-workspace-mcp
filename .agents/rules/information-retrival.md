# Information Retrival

## Documentation

Always use Context7 when I need library/API documentation, code generation, setup or configuration steps without me having to explicitly ask.

## Web search and web scraping

Use tavily_search for web search. Set the "search_depth" = "advanced" and "include_answer" = "advanced". Use tavily_extract to read or scrape websites, use "extract_depth" = "advanced" if detailed information are necessary.
